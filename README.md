## 🚀 Panduan Instalasi & Penggunaan

### 1. Windows Desktop (.EXE Setup)
1. Unduh berkas **`IstiqomahBulusariStock-Setup.exe`**.
2. Klik ganda untuk menjalankan installer.
3. Ikuti wizard instalasi:
   - Pilih direktori instalasi.
   - Centang opsi **Buat Pintasan di Desktop** (*Create Desktop Shortcut*).
4. Klik **Pasang** (*Install*).
5. Setelah selesai, ikon resmi **Istiqomah Bulusari Stock** akan muncul di Start Menu dan Desktop.
6. Aplikasi dapat dilepas pemasangannya kapan saja melalui **Windows Settings > Apps & Features / Programs & Features**.

### 2. Android Mobile (.APK)
1. Unduh berkas **`IstiqomahBulusariStock.apk`** ke perangkat Android staf lantai gudang.
2. Buka berkas APK dan izinkan instalasi dari sumber ini (*Install unknown apps*).
3. Buka aplikasi **Istiqomah Bulusari**.
4. Aplikasi siap digunakan secara 100% luring (*offline-first*) dengan pemindai kamera barcode terintegrasi.
